# IA Para Todos — Plataforma Web de Aprendizaje Autónomo sobre Uso Ético y Normativo de la IAG

Proyecto de **Análisis y Modelamiento de Software** orientado a diseñar una plataforma educativa web para el aprendizaje autónomo del uso práctico, ético y normativo de la Inteligencia Artificial Generativa en entornos académicos y laborales.

## Autor
* **Rubén Salazar Chavarría** — Ingeniería de Software / Ciencias de la Computación (UACM)

## Fases del Proyecto
1. **Planeación:** Problemática, objetivos, alcance (módulos de *Uso Práctico*, *Ética* y *Normatividad*) y estudio de factibilidad.
2. **Análisis y Modelamiento:** Requerimientos Funcionales (`RF-01` a `RF-08`), No Funcionales (`RNF-01` a `RNF-05`) y diagramas UML (Clases, Casos de Uso y Actividades).
3. **Diseño:** Wireframes de baja fidelidad en Balsamiq, diseño de base de datos conceptual (E-R) y físico (relacional), y guía de interfaz gráfica.
4. **Gestión Ágil (SCRUM):** Product Backlog, Sprints, Historias de Usuario, Tasks y Bugs gestionados en Jira Software (`Clave: IAPT`) e integrados con GitHub.

## Herramientas Utilizadas
* **Modelado y Diseño:** PlantUML, ArgoUML, Balsamiq Wireframes
* **Gestión Ágil y Control de Versiones:** Jira Software Cloud, Git, GitHub
